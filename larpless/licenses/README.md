# Third-party licence texts

Licences that npm and CocoaPods don't supply, for things bundled by hand: the Inter and Instrument Serif fonts (`OFL-1.1.txt`), the Ultralytics YOLO11n model (`AGPL-3.0.txt`, copied from the `ultralytics` package; the app's own `LICENSE` is the same text), the models the app downloads at onboarding (`Apache-2.0.txt`, from apache.org), and the Windows build's native libraries: ONNX Runtime, Hermes (`NOTICE-hermes.txt`, which also covers ICU), WebView2 and the VC++ runtime forwarders from their NuGet packages, and Folly, fmt and fast_float from `node_modules/react-native-windows/external/` after a Windows build. ONNX Runtime's own `ThirdPartyNotices.txt` is too big for the in-app page, so `LarpLess.vcxproj` packages it next to `LarpLess.exe` instead. `scripts/acknowledgements.mjs` reads them through its `EXTRAS` list, adds each component's copyright line, and writes `src/legal/acknowledgements.json` for the in-app Acknowledgements page.

When you bundle a new font, model or other file by hand, add its licence here and an entry to `EXTRAS`, then run `node scripts/acknowledgements.mjs`.
